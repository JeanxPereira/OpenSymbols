# P6 — Finishing: exact weights, symbol scale, localized drawings, a smaller package, npm

**Plan 6.** The five plans before this one built the decoder, the runtime, the demo and the
effects. This one closes what keeps the package from being finished: the six intermediate
weights are approximate, the symbol scale (Small / Medium / Large) is missing, localized
drawings are not generated, the generated package is 92 MB, and the packages are not ready to
publish.

Facts read for this plan in CoreUI 26A5416b (`+[CUIVectorGlyphMutator _interpolationData]`,
`_scalarsForGlyphContinuousWeight:…`, `transformForGlyphSize:`, `applyDeltasWithScalars:…`); the
facts file is named in each task brief. Measurements of the package come from a generated
package of the real catalog.

## The contract (committed before the tasks)

- **Format 2** (`packages/core/src/format.ts`): `SymbolWire` is what `generate` writes; master
  args delta-encoded (`d[i] = a[i] − a[i − 2]`), no `argCounts` (arity of `M L Q C Z`), layer
  styles without `opacity: 1` / `clearBehind: false`, layer `anim` without the default-valued
  keys, `locales` by BCP-47 tag. `decodeSymbol` (`packages/core/src/decode.ts`) expands it once
  into `SymbolData` (the in-memory form, `v: 1`), which every runtime keeps reading.
  `createIcon` and `SymbolIcon` accept both. `FORMAT_VERSION` is 2.
- **Props** (`packages/react/src/create-icon.tsx`): `scale?: "small" | "medium" | "large"`
  (default `"medium"`), `locale?: string`.

## Behaviour

**Weights.** `p = R + x·(UL − R) + y·(B − R)` per value, as today; `(x, y)` comes from CoreUI's
table of 6 sizes (0.2, 0.5, 1.0, 1.276, 1.647, 2.0) × 9 weights (keys −0.8, −0.6, −0.4, 0, 0.23,
0.3, 0.4, 0.56, 0.62), float64. A weight on the 1..9 scale maps to its key; a fractional weight
interpolates linearly between the neighbouring keys, a size between table sizes bilinearly;
nothing is clamped. The same scalars apply to the viewBox, the metrics, the insets and the
anchors. The six intermediate weights stop being an approximation.

**Scale.** `S` = 1, 1.276, 1.647 for small, medium, large. It selects the weight scalars' size
row, scales the glyph (path, viewBox, insets, anchors) about the master's origin, and in text
layout moves the baseline to `S·b + K·(S − 1)·X`, with `K = 0.352294921875` and `X` the
reference point size (`[INF]`); cap height is not scaled. In box layout the glyph still fits its
box: scale changes its weights and proportions, not its pixel size. Default `"medium"`, like
SwiftUI's `imageScale`.

**Locales.** `generate` writes each localized drawing into its base symbol's `locales`, by the
catalog's tag: token-13 renditions first, then the `<name>.<suffix>` facet (05 §4.3; a `zh`
facet is stored as `zh-Hans` and `zh-Hant` when the catalog's tags say so, else `zh`). The 132
`.rtl` facets become the base symbol's Direction 5 variants when it has none. A `locale` prop
picks the exact tag, then its language subtag, else the base drawing. Localized facets stop
being generated as their own symbols' list in `index.json` "localized"; they remain listed
there with the locale they became.

**Size.** No `chunks/` in the package: the demo server builds each chunk on request from
`symbols/*.js` and caches it. One shared `symbol.d.ts` for every module, through the
`exports` map's `types`. `viewBox` rounded to 6 significant digits. Target: under 30 MB raw,
under 6 MB as a tarball, for the real catalog. Measured on 26A5416b: 42.6 MB raw in 7,214 files and 5.9 MB as a tarball; the raw target
is missed by the 1,615 localized drawings (6.6 MB), which the package did not carry before.

**npm.** Version `0.1.0` for the five packages; `prepack` builds and runs the Apple-data check;
`publishConfig.access: "public"`; `engines`; a README per package; peer ranges that match
0.1.x; a `default` export condition where it is safe. Publishing itself is the user's call.
