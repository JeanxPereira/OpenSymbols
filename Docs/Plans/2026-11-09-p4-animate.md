# P4: Symbol Effects Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `@opensymbols/animate` plays every SF Symbols effect keyframe for keyframe (Appear, Disappear, Bounce, Breathe, Draw On/Off, Pulse, Rotate, Scale, Replace, Magic Replace, Wiggle, static Variable Color), React components gain SwiftUI-shaped effect props, and the demo inspector gains an Animation panel with a timeline scrubber.

**Architecture:** The engine is a pure function `sample(drawing, spec, t) → LayerState[]` over keyframe tracks and RenderBox's 42 cubic timing curves, written from a new effects specification in `Docs/format/07-effects.md` and `08-draw-clip.md`. `SymbolIcon` exposes a per-layer DOM structure (one `<g>` per layer inside the transformed group, plus mask copies for knockouts) that an opt-in driver (`@opensymbols/animate/react`) writes into from one shared `requestAnimationFrame` loop, never through React state. The generator carries the extra data the engine needs (rotation anchor, metric centre) in the format.

**Tech Stack:** TypeScript strict ESM, Vitest + happy-dom, React 19, existing packages (`decode`, `core`, `react`, `cli`, `apps/demo`).

**Spec:** `Docs/Specs/2026-11-09-opensymbols-design.md` §2 goals 6 and 8, §4, §9, §12.3 (Animation and Replace).

**Plan 4 of 5.** Variable Color's animated forms (iterative, cumulative, reversing) are P5 (spec §9.2); P4 ships static Variable Color only. If Task 1 finds their timing already read in the reference material, it documents it and the controller re-scopes P5.

## Global Constraints

- Reference material, read-only, never named in the repo, never pasted verbatim: the private research notes the format docs came from. Facts go into OpenSymbols' docs in their own words with seals (`[BIN]` with image/symbol/address, `[CAR]`, `[INF]`, `[OBS]`).
- Every animation constant in code cites `Docs/format/07 §…` or `08 §…` (spec §4 "a number with no source").
- The engine has no clock and no DOM: `sample` is pure and deterministic.
- `@opensymbols/react` does not depend on `@opensymbols/animate`; effects work only after `import "@opensymbols/animate/react"`. A static-only app's bundle contains no engine code (checked in Task 8).
- `prefers-reduced-motion: reduce` → effects jump to their end state.
- No Apple data in git or tarballs; `pnpm check:pack` green with the new package.
- Commits: conventional prefixes (`docs:`, `decode:`, `core:`, `animate:`, `react:`, `cli:`, `demo:`), no AI attribution.

## Review Focus

1. A symbol with a single motion group, and one with 9+ groups: by-layer stagger must stay within the effect's total duration (the budget-with-ceiling rule) and never produce negative or NaN times. Test in Task 4.
2. `t` outside `[0, duration]`, negative `speed`, `speed = 0`, NaN: clamp or reject predictably; `sample` never returns NaN. Test in Task 3.
3. Two animating icons with knockouts on one page: each icon's mask copy follows its own knockout layer's transform. Test in Task 7.
4. Replace between symbols with different layer counts (and Magic Replace with no shared tags): falls back the way the spec docs say, never throws. Test in Task 5.
5. Unmounting an icon mid-animation removes it from the shared loop (no leak, no writes to detached nodes). Test in Task 7.

### Task 3: `@opensymbols/animate`: curves, tracks and the public contract

**Files:**

**Interfaces:**

  - `interface Spec { kind: EffectKind; repeat: "once" | "continuous"; speed: number; byLayer: boolean; reversed: boolean; variableValue?: number; direction: "default" | "up" | "down"; breathePlain: boolean; replaceStyle: "plain" | "downUp" | "upUp" | "offUp"; replaceHalf: "out" | "in"; drawIndividually: boolean; drawReversedOrder: boolean; renderingMode: RenderingMode }` and `defaultSpec(kind): Spec`

  - `sample(d: AnimDrawing, spec: Spec, t: number): LayerState[]`, `duration(d, spec): number`, `loopStart(d, spec): number`
  - `curve(id: number): (x: number) => number` (the 42 curves, Docs/format/07), `evalTrack(track, t)`
